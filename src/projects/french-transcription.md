# French Transcription

Learning French from YouTube videos is slow if you're constantly switching between Google Translate and YouTube captions. I made an app that lets you read the transcription, hover over a word and translate it, and add it to your vocab list.

**Stack:** Claude API for translations · AICSS Orbs for loading animation · Shadcn UI

## What it does

- Plays a YouTube video with its transcript synced underneath — the current line highlights and scrolls as the video plays; click any line to jump there
- Hover a word (or select a phrase) for an English translation
- Save words and phrases to a vocab list you can export as CSV
